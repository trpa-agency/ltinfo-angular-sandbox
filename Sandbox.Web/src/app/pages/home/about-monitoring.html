Each monitoring program has a page that describes what is measured, how and where it is measured, who does the work, and what the record shows so far, with charts, a site map, and photos where the program has them.

Programs are grouped by the same 10 threshold categories as the Threshold Dashboard. Monitoring data feed that dashboard, where each indicator is evaluated against its standard every four years.

Programs, partners, photos, and site locations come from Lake Tahoe Info. The site map on this page shows one point for each mapped site, area, or line.

Measurement charts and full site shapes on the program pages are read live from the TRPA LTInfo_Monitoring map service.
